RestoreInventory

A Fabric mod that automatically backs up your inventory and lets you restore it on demand — across deaths, mistakes and even mod updates.

Features

  • Four save slots per player: Auto (short), Auto (long), Manual and Death.
  • Configurable auto-save intervals for the Auto slots.
  • Auto-save just before death into the dedicated Death slot.
  • Undo restoration (/restoreinv undo) — the current inventory is saved first.
  • Inventory preview GUI (9×6) showing armor, main inventory, hotbar and off-hand.
  • Detailed tooltips: relative time, item count and best tool.
  • Pin protection: right-click to prevent overwriting saves.
  • Configurable number of saves per slot (1–9).
  • Restore sound toggle and per-player settings.
  • Multilingual (English / German).
  • Asynchronous saving off the server thread.
  • Saves stored in restoreinv/<uuid> and persist across mod updates.
  • Supported versions: 1.21–1.21.1, 1.21.2–1.21.4, 1.21.9–1.21.11.
  • Commands: /restoreinv 1|2|3|4, save, undo, saves, config, version.
  • Permissions: restoreinv.admin and restoreinv.restore (OP fallback).
  • MIT license; saves survive updates and are backward-compatible.

Commands

Command Description
/restoreinv 1|2|3|4Restore from Auto-short / Auto-long / Manual / Death.
/restoreinv saveSave current inventory to the Manual slot.
/restoreinv undoUndo the last restoration.
/restoreinv savesOpen your save list GUI.
/restoreinv configOpen the configuration GUI (admins only).
/restoreinv versionShow the mod and Minecraft version.
Aliases /rinv, /restoreInv Shortcuts for /restoreinv.

Permissions

Node Effect
restoreinv.adminAccess config GUI, admin panel, restore other players.
restoreinv.restoreRestore your own inventory (/restoreinv and undo).
